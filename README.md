# Adam's Mobile Mechanic — Sample Website

This is a **free sample website** built for Adam's Mobile Mechanic by [Clementine Web Co.](https://clementinewebco.com), a small web design studio based in St. Petersburg, FL. It's not live yet and isn't an official Adam's Mobile Mechanic website, just a preview of what one could look like.

## What's in this repo
A simple, framework-free, multi-page website:
- `index.html` — home
- `reviews.html` — a real, verified customer review, plus a link to the Yelp listing
- `gallery.html` — real job photos, coming soon
- `about.html` — Adam's story, service area, mobile-vs-shop comparison
- `services.html` — service list and starting pricing
- `contact.html` — call and text CTAs
- `styles.css` — all styling
- `script.js` — nav, scroll reveal, and the one-time review popup

No build tools, no installs, open `index.html` in any browser to view it, or visit the live preview at **https://dljackson97.github.io/adams-mobile-mechanic/**.
